# W84 Studio · sürümler

W84ME2JOIN YouTube kanalının kapak aracı **W84 Studio**'nun kurulum ve güncelleme dosyaları.
Kaynak kod bu depoda değildir.

## Kurulum

1. Son sürümün **Assets** bölümünden `W84Studio-win-Setup.exe` dosyasını indir.
2. **Engeli kaldır:** dosyaya sağ tıkla → Özellikler → en alttaki **Engellemeyi kaldır** kutusunu işaretle → Tamam.
   Kurulum programı imzasız olduğu için Windows internetten indirilen dosyayı işaretler; bu adımla
   "bilgisayarınız korundu" uyarısı çıkmaz. (Atlarsan: "Ek bilgi" → "Yine de çalıştır".)
3. Dosyayı çalıştır. Yönetici izni istemez; masaüstüne ve Başlat menüsüne kısayol koyar.
4. İlk açılışta "İlk kurulum" penceresi açılır: kanal sahibinin verdiği `client_secret.json` dosyasını seç, **Bağlan**.

## Güncellemeler

Kurulan uygulama yeni sürümü buradan kendiliğinden indirir; güncellemelerde uyarı çıkmaz.
Uygulama yalnızca kanal sahibinin verdiği bağlantı dosyasıyla kanala bağlanabilir.
